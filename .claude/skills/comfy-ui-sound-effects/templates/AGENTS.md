# Sound templates bundled with the skill

Available in every project. A project can add its own in its "ComfyUI sound templates" folder;
a project template with the same name, or one marked default there, wins.

- [stable-audio-3-sfx/](stable-audio-3-sfx/stable-audio-3-sfx.md) — **default**. Game sound effects, Stable Audio 3 + LLM prompt enhancer.
