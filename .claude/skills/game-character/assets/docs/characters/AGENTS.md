# AGENTS.md

The characters of the game, for people: who they are, how they look, sound
and behave, and their place in the story. One folder per type, one folder
per character (`<type>/<name>/<name>.md`, the character bible). No engine
details: what each character needs in the game, and where its files are, is
in [prototype/characters/](../../prototype/characters/AGENTS.md).

Managed with the `game-character` skill. A type's `AGENTS.md` says which
sections its bibles have.
