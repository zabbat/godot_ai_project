# Image templates bundled with the skill

Available in every project. A project can add its own in its "ComfyUI image templates" folder;
a project template with the same name, or one marked default there, wins.

- [z-image-turbo/](z-image-turbo/z-image-turbo.md) — **default**. General 2D game art; ComfyUI's own Z-Image Turbo template, built-in nodes only, no LoRA, 480x480.
- [z-image-turbo-res4lyf/](z-image-turbo-res4lyf/z-image-turbo-res4lyf.md) — the same with the RES4LYF ClownsharK sampler; needs the RES4LYF node pack.
- [cutout_transparent.json](cutout_transparent.json) — not a generation template: the "cut out" graph as a canvas workflow (see "cut out" in SKILL.md).
