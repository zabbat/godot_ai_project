# Game data

The game's current content with exact values: constants, rules, content
lists and levels. This is the record to rebuild the Godot data from. The
design behind it is in [docs/game_design/](../docs/game_design/AGENTS.md).

**Keep in sync**: when a value changes in Godot (`.tres`, a scene, a
constant), change it here in the same step, and the other way around. Say
where each value lives in Godot (file and field).
