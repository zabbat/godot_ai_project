# AGENTS.md

The game's visual style: how its art should look. These are standard
documents that exist in every project; until a style is chosen, a document
(or a part of it) says "No style defined yet". Style references (images
showing what we aim for) are in [../references/](../references/AGENTS.md).
Read the matching style doc before generating, choosing or making art. If
the part you need says "No style defined yet", ask the user before
inventing one, then write the decision into the doc.

Below is a short description of each document in this folder.

- [2d_style.md](2d_style.md) — 2D art (characters, UI, icons) and prompt keywords for generation. No style defined yet.
- [3d_style.md](3d_style.md) — 3D art (characters, props, buildings, environment). No style defined yet.
