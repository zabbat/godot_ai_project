# AGENTS.md

This folder contains the game design: what the game is, how it plays, how
it looks and sounds, and why. It does not describe the engine. How the
design is built in Godot, with exact values, is in
[prototype/](../prototype/AGENTS.md).

Below is a short description of each document/subfolder in this folder.

- [game_design/](game_design/AGENTS.md) — Game design material, from brainstorming to detailed systems, plus the standard docs `audio.md` and `menus.md`.
- [style/](style/AGENTS.md) — Visual style (standard): `2d_style.md` and `3d_style.md`.
- [references/](references/AGENTS.md) — Reference images and other material showing what we aim for (e.g. a drawing style). Guides docs and prompts; never used in the game.
