# 2D style

This document defines the visual style for the game's 2D art. It is the
reference for artists, for image generation prompts, and for any 2D art
added to the game. The 3D style is in [3d_style.md](3d_style.md).

## Scope

One row per kind of 2D art. **Template** is the ComfyUI image template it is
made with (a project template in `tools/comfy-ui/templates/images/`, or one
bundled with the `comfy-ui-images` skill, e.g. `z-image-turbo`); **Style** holds
the prompt keywords, size, framing and background.

| 2D art | Template | Style |
|---|---|---|
| Characters (portraits, character art) | - | No style defined yet. |
| UI (buttons, panels, icons) | - | No style defined yet. |
| Items and loot icons | - | No style defined yet. |
